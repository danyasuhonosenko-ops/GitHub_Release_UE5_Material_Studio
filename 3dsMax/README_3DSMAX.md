# Corona ComfyPBR Studio & UE5 Exporter (v2.1.1 — GitHub + OTA Edition)

Companion **Autodesk 3ds Max 2022–2026 + Corona Renderer** PySide2/PySide6 plugins.

## Quick Install
1. Run `INSTALL_3DSMAX_PLUGIN.bat` (auto-detects your 3ds Max `ENU` profile directory).
2. Restart 3ds Max -> **Customize -> Customize User Interface -> Toolbars -> Category: AI ArchViz**.
3. Drag **Corona ComfyPBR** and **Corona -> UE5** onto your toolbar.

## Over-The-Air (OTA) Updates
- Automatically checks for new patches via Audit / Gateway OTA (`Check Updates (OTA)` in Account drawer).
