# AI PBR Material Studio for Blender 3.6–5.1+ (v2.1.1)

**Cycles & EEVEE Add-on** sharing the exact same Cloud GPU Gateway, 12-word keys, Copy ID wallet, free instant Physical Metal Synthesis (`0 Gens` Polished & Brushed), free Local ComfyUI mode, and free Local PBR Maps Assembler (`From Maps`).

## Quick Install (EN)
- **Blender 4.2 – 5.1+ (Extension):** Drag & drop `AIPBRMaterialStudio_Blender_v2.1.1.zip` into the Blender window, or open **Edit -> Preferences -> Get Extensions -> Install from Disk...**.
- **Blender 3.6 – 4.1 (Legacy Add-on):** Open **Edit -> Preferences -> Add-ons -> Install...** and pick `AIPBRMaterialStudio_Blender_Legacy_v2.1.1.zip`, then enable **AI PBR Material Studio**.
- Open the studio panel in **3D Viewport -> Sidebar (`N` key) -> AI PBR Studio**.

## Быстрая установка (RU)
- **Blender 4.2 – 5.1+ (Extension):** перетащите `AIPBRMaterialStudio_Blender_v2.1.1.zip` прямо в окно Blender или выберите в **Edit -> Preferences -> Get Extensions -> Install from Disk...**.
- **Blender 3.6 – 4.1 (Legacy):** **Edit -> Preferences -> Add-ons -> Install...** -> `AIPBRMaterialStudio_Blender_Legacy_v2.1.1.zip`.
- Панель открывается в **3D Viewport -> боковая панель `N` -> AI PBR Studio**.
